# Google Health Data Loader

Google Health Data Loader is a personal tool by Renedix Development. It copies the owner's own
**sleep** and **heart rate** data from the [Google Health API](https://developers.google.com/health)
into the owner's private AWS account, so the owner can analyse it.

It has no public sign-up and no user interface. It runs on a schedule in the owner's AWS account,
using access the owner granted once through Google's consent screen.
